## Overview
In this section we'll be dealing with variable on exponents, 
using LTE, Zsigmondy, etc. to solve the problem. 

## Orders (review)

This should be a review for most of you. 
The *order* of $a\pmod p$, sometimes denoted as $\text{ord}_p (a)$ (pretty much similar to the $\log$ function), is the smallest positive integer $m$ such that $a^m\equiv 1\pmod p$. 

Also note that $a^{p-1}\equiv 1\pmod p$, thus $\text{ord}_p (a)\mid p-1$. 
This is more useful when $p-1$ has few prime factors, e.g. $p=2^{2^k}+1$. 

Also, the existance of *primitive roots* are pretty important too, which is denoted as $g$ and $g^0, g^1, \dots, g^{p-1}$ passes through all the numbers in the set $\{1, 2, \dots, p-1\}$. 

## The v_p argument 

Once we get the relation that $p\mid m$, it is quite natural to think how many times $m$ is divisible by $p$. This motivates us to the following definition. 

-Let $p$ be prime and define a function $\nu_p\colon \mathbb{Q}\mapsto \mathbb{Z}$ as following: If $n$ is an integer and $e$ is the largest integer such that $p^e\mid n$, then $\nu_p (n)=e$. For $n=a/b$, define $\nu_p (n)=\nu_p (a)-\nu_p (b)$. By convention we define $\nu_p (0)=\infty$. 

**problem**: Convince yourself that this definition makes sense. 

Let greek letter $\nu$ is read as ``nu'', but people often use the alphabet $v$ because they're lazy. 

There are a few results about this function. 

- $\nu_p (x+y)\ge \min \{\nu_p(x), \nu_p (y)\}$ and if $\nu_p (x)\ne \nu_p (y)$ then the equality holds. 
- $\nu_p (xy)=\nu_p (x)+\nu_p (y)$. 

Try to prove these results, as it's not really hard. 

## Lifting Exponents 

The v_p function is not going to be good at most problems with only the above results. In fact, there are one more nice property of this function: the **Lifting The Exponents** lemma, often abbreviated as LTE. 

**definition**. Let $p$ be a prime, and $a$, $b$ are integers. Suppose that 
- $p>2$; 
- $p\nmid a, b$; 
- But $p\mid a-b$. 
Then for any positive integer $n$, we have the equation 
$$
\nu_p (a^n-b^n)=\nu_p (a-b)+\nu_p (n). 
$$

Always don't forget to confirm this three condition! It's really easy to mess up since each looks like an edge case. 

This time, the proof is not going to be that easy and it is proven by induction on $n$. See https://en.wikipedia.org/wiki/Lifting-the-exponent_lemma for details. 

Note that if $n$ is odd, we can derive to the equation of $\nu_p (a^n+b^n)$ by flipping the sign of $b$. 

## Zsigmondy theorem

Next, we have the **Zsigmondy** theorem, which is also quite mondatory for some intermediate-to-above level problems. There are two versions but they're essentially the same. The statement is: 

**Statement 1**: Let $a>b>0$ be a coprime integers, then for any integer $n>1$, $a^n-b^n$ ``generates a new prime factor'', that is, there exists are prime dividing $a^n-b^n$ but not dividing $a^k-b^k$ for each $n>k$. But, with two edge cases as an exception: 
- $n=2$ and $a+b$ is a power of $2$. 
- $(a, b, n)=(2, 1, 6)$. 

Similarly, 

**Statement 2**: $a^n+b^n$ generates a new prime factor for any $n>1$ with an exception 
- $(a, b, n)=(2, 1, 3)$. 

The Zsigmondy theorem is useful for bounding by prime factors, like in the situation $m^n=a^k-b^k$. 


**Example** (USA January TST 2012, this problem is quite silly): Find all positive integers $a, n\ge 1$ such that for all primes $p$ dividing $a^n-1$, there exists a positive integer $m$ less than $n$ such that $p\mid a^m-1$

## Warm-Up Examples

### Example 1: LTE Problem

Let $p$ be an odd prime. Your goal is to prove that for any positive integer $n$, $p^n \parallel (p+1)^{p^{n-1}} - 1$.

First, we will let $x = p+1$ and $y = 1$. Note that $p \mid (x-y)$ since $(p+1) - 1 = p$, and $p \nmid x, y$. Now, since the exponent $k = p^{n-1}$ is a positive integer and $p$ is an odd prime, we can simply use LTE directly. We get $v_p((p+1)^{p^{n-1}} - 1) = v_p((p+1) - 1) + v_p(p^{n-1})$. Simplifying the right side gives us  $v_p(p) + (n-1) = 1 + n - 1 = n$. By definition, we have proven $p^n \parallel (p+1)^{p^{n-1}} - 1$.

### Example 2: LTE Special Case

Your goal is to find all positive integers $n$ such that $2^{n+2}$ divides $3^n - 1$.

We will be using the specific $2$-adic version of LTE. Firstly, if $n$ is odd, then $3^n - 1 \equiv 2 \pmod 4$, which means that $v_2(3^n - 1) = 1$. The condition requires $1 \ge n+2$, which gives no solutions. Now, if $n$ is even, we can simply apply special case LTE for the prime $2$ to get $v_2(3^n - 1) = v_2(3-1) + v_2(3+1) + v_2(n) - 1$. This simplifies to $1 + 2 + v_2(n) - 1 = v_2(n) + 2$. The divisibility condition requires $v_2(n) + 2 \ge n + 2$, which simplifies to $v_2(n) \ge n$. Since $2^{v_2(n)} \le n$, the inequality $n \le v_2(n)$ is impossible for all positive integers $n$. So, sadly, there are NO integer solutions.

### Example 3: Zsigmondy!!!

Your job is to find all positive integers $n$ such that $n^2$ divides $2^n - 1$.

First of all, the trivial case $n=1$ clearly works. For $n > 1$, we will let $p$ be the smallest prime factor of $n$. Now, since $n^2 \mid 2^n - 1$, we must have that $p \mid 2^n - 1$. Let $d = \text{ord}_p(2)$, which means that $d \mid n$. Furthermore, by FLT, we also know $d \mid p-1$. Because $d$ divides $p-1$, any prime factor of $d$ must be strictly less than $p$. However, since $d \mid n$ and $p$ is already defined as the smallest prime factor of $n$, the only way to avoid a contradiction is if $d = 1$. This implies $2^1 \equiv 1 \pmod p$, which means $p \mid 1$, which is impossible. Therefore, $n=1$ is the only solution.

### Example 4: Spicy Problem

Let $a, b$ be coprime positive integers and $p$ be a prime such that $p \mid a+b$. If $v_p(a^n + b^n) = v_p(a+b) + 1$, your job is to determine all possible values for the exponent $n$ when $p$ is odd.

Because $p \mid a+b$ and $p$ is an odd prime, we can apply LTE for an odd exponent $n$. If $n$ were even, $a^n + b^n \equiv 2a^n \pmod p$, and since $\gcd(a,b)=1$, $p \nmid a$, meaning $v_p(a^n+b^n) = 0$, contradiction. Thus, $n$ must be odd. Applying LTE for odd $n$ gives $v_p(a^n + b^n) = v_p(a+b) + v_p(n)$. We are given that this expression equals $v_p(a+b) + 1$. Equating them, and simplifying gives us $v_p(n) = 1$. So, $n$ must be any odd multiple of $p$ that is not a multiple of $p^2$, which can be written as $n = p \cdot k$ where $\gcd(k, 2p) = 1$. :)

### Example 5: Another Spicy Problem

Your goal is to prove that $7^n - 5^n = 2^k$ has NO integer solutions for $n > 1$.

If $n=2$, $7^2 - 5^2 = 24$, which is not a pure power of $2$. For $n > 2$, we can use Zsigmondy's Theorem to guarantee that $7^n - 5^n$ must contain AT LEAST ONE primitive prime divisor $p$ because the base pair $(7,5)$ and $n$ do not match the $(2,1,6)$ exception. By definition, this primitive prime $p$ must satisfy $p \nmid (7^1 - 5^1)$, which meansthat $p \nmid 2$. Therefore, $p$ HAS TO be an odd prime factor of $7^n - 5^n$. However, now notice that the other side of the equation is $2^k$, which contains no odd prime factors. So, no solutions can exist for any $n > 1$.
